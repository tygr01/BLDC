# BLDC
2024 Teknofest Efficiency Challenge yarışlarında kullanılmak üzere Zeugma Elektrikli aracı için tasarlanmıştır. Aracın 4 çeker olması sebebiyle 4 adet üretimi yapılmıştır. Takım tarafından geliştirilen yazılım ile aracımızı harekete geçirmiştir. Yazılım ve donanım tarafındaki eksikleri nedeniyle tam verimde kullanılamamıştır. Tasarımda kullanılan mosfetlerin yükünün azaltılması için 3 paralel mosfet toplamda 18 mosfet kullanılmıştır. Bu mmosfetlerin açılması için yüksek akım özellikli kapı sürücüleri ve buna uygun kapı sürücü devresi tasarlanmışıtr. Motor sürücünün kontrolü STM32F103CBT6 işlemcisi tarafından yapılmaktadır. Kontrol kısmı gömülü olarak tasarlanmış ve gerekli haberleşme sıcaklık ölçümleri sensör bağlantı pinleri kullanıcıya sunulmuştur.
